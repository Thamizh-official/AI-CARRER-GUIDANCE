====================================================================
   AI CAREER GUIDANCE PLATFORM - HOW TO RUN ON ANY PC
====================================================================

NO NODE.JS OR DATABASE INSTALLATION NEEDED! (Fully Portable)

HOW TO RUN:
1. Copy the "ai-career-guidance" folder to the other PC (Desktop or C: drive).
2. Open the folder.
3. Double-click on "LAUNCH.bat".
4. The server will start and automatically open your web browser at:
   http://127.0.0.1:3005

FEATURES:
- AI-Powered Career Guidance & Degree Progression Engine.
- Embedded SQLite Database (careers.db).
- Embedded Node.js runtime (node.exe).
- Works 100% offline without internet.
- Works on Windows 10, Windows 11, etc.
